# Welcome to scpcn-ui

**scpcn-ui** is an open-source UI component library that brings the iconic visual style of the SCP Foundation to modern web applications. Whether you're building a fan project, a containment simulation, or just want that classified institutional aesthetic, this library has you covered.

## What is scpcn-ui?

This project provides a collection of beautifully crafted UI components inspired by the timeless design language of the SCP Foundation

All components are designed to be **copy-paste ready** and work seamlessly with modern frameworks like React, Next.js, and more.
